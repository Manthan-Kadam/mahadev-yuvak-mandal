**Shree Ganesh Mahotsav - 12 Months Fund Tracker & Automation Portal**

---

## 🌟 મુખ્ય વિશેષતાઓ (Key Features)

1. **૧૨ મહિનાનો સંપૂર્ણ લેખા-જોખા (12-Month Matrix View)**:
   - દરેક સભ્યના ૧૨ મહિનાના ફાળાની વિગત (ઓક્ટોબર થી સપ્ટેમ્બર).
   - લીલો રંગ: ફાળો જમા છે (Amount & Payment Mode).
   - લાલ રંગ: ફાળો બાકી છે (Click to Pay).

2. **WhatsApp ઓટોમેશન (1-Click Automation)**:
   - **ગ્રૂપ રિપોર્ટ**: ૧-ક્લિકમાં આખા વોટ્સએપ ગ્રૂપ માટે સુંદર ગુજરાતી રિપોર્ટ તૈયાર થાય છે (કોણે આપ્યા, કોના બાકી, કુલ કેટલા ભેગા થયા).
   - **વૈયક્તિક રીમાઇન્ડર**: જે સભ્યનો ફાળો બાકી હોય તેને સીધો પર્સનલ વોટ્સએપ મેસેજ મોકલી શકાય છે જેમાં બાકી રકમ અને UPI ID સામેલ હોય છે.
   - **ડિજિટલ પાવતી (Digital Receipt)**: પેમેન્ટ જમા થતાં જ સભ્યને તરત જ વોટ્સએપ પર રસીદ મોકલી શકાય છે.

3. **ઓનલાઈન UPI / QR કોડ**:
   - ખજાનચીનો UPI ID સેટ કરી શકો છો (Google Pay / PhonePe / Paytm).
   - વેબસાઈટ પર લાઈવ QR કોડ દેખાય છે જેથી કોઈપણ સભ્ય સીધો સ્કેન કરીને પૈસા ચૂકવી શકે છે.

4. **ગણેશ મહોત્સવ ખર્ચનો હિસાબ (Festival Expense Tracker)**:
   - મુર્તિ, મંડપ, સાઉન્ડ/ડીજે, પ્રસાદ, વિસર્જન વગેરેના તમામ ખર્ચની નોંધ.
   - કુલ ફાળો - કુલ ખર્ચ = હાથ પર શિલક (Surplus Balance).

5. **ઓટોમેટિક ડેટા સેવ અને બેકઅપ**:
   - બધા ડેટા આપમેળે બ્રાઉઝરમાં સેવ રહે છે.
   - Excel (CSV) ડાઉનલોડ અને ૧-ક્લિક JSON બેકઅપ ઉપલબ્ધ છે.
